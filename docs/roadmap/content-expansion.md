# コンテンツ拡張(Arxiv論文等) 設計書(ロードマップ)

- 日付: 2026-09-17
- 位置づけ: 今後の展望として検討した設計。実装計画(タスク分解)はこの設計を元に着手時に別途作成する
- 分類: アーキテクチャレベル(既存のカテゴリ体系を拡張する「ジャンル」概念を新設する)
- 関連spec: `docs/roadmap/account-personalization.md`(未登録/無料/有料の3段階モデルと合わせて読むこと)

## 背景・目的

現状のRSS Summaryはテック系ニュース17フィードのみを対象にしている。本設計は、まず**Arxiv論文**を対象ジャンルとして追加し、将来的に他ジャンルへも同じ仕組みで拡張できるパターンを確立することを目的とする。

`docs/roadmap/account-personalization.md`で合意した3段階モデル(未登録/無料/有料)における軸は「情報量は全層に開放し、AI要約の深さ・パーソナライズ度合いだけが段階的に上がる」というものである。ジャンルを増やすことは、この3段階すべてを底上げする(未登録層により多くの情報を見せ、無料層の「整理する」対象を増やし、有料層のパーソナライズ対象を広げる)ための施策と位置づける。

## データソース: Arxiv公式RSS/Atomフィード

Arxivは日次の新着論文を配信する公式フィードを提供している(調査済み、2026年時点):

- URL形式: `https://rss.arxiv.org/rss/{category}` (RSS 2.0) または `https://rss.arxiv.org/atom/{category}` (Atom)
- 複数カテゴリを`+`で結合して1本のフィードにできる(例: `https://rss.arxiv.org/rss/cs.AI+cs.CL+cs.CV+cs.LG`)
- 認証不要、公式の日次新着フィードのため`export.arxiv.org/api/query`(検索API、3秒に1回のレート制限あり)のような重い制約がない
- 既存の`apps/backend/src/fetch/`はRSS1.0/2.0/Atomいずれも正規化済みのため、**新規パーサー実装は不要**。既存の`FEEDS`設定にURLを1本追加するだけで取得基盤に乗る

**対象カテゴリ(初期案)**: `cs.AI`(人工知能) / `cs.CL`(自然言語処理) / `cs.CV`(コンピュータビジョン) / `cs.LG`(機械学習)。この4カテゴリでも1日あたり数百件規模の新着が見込まれるため、既存の「全記事をカテゴリ分類+あらすじ、そのうち数件をピックアップ+要約」というGeminiの処理パターンがそのまま活きる。

## ジャンルという新しい軸

既存の6カテゴリ(クラウド・インフラ、開発・プログラミング等)を「**テック**」ジャンルとし、Arxiv論文を「**論文**」ジャンルとして新設する。ジャンルはカテゴリの上位概念であり、今後さらにジャンルを追加できる構造にする。

```
digest
├── genre: テック
│   ├── category: クラウド・インフラ (picks / others)
│   ├── category: 開発・プログラミング (picks / others)
│   └── ...(既存6カテゴリ)
└── genre: 論文
    ├── category: AI/機械学習 (picks / others)
    ├── category: 自然言語処理 (picks / others)
    ├── category: コンピュータビジョン (picks / others)
    └── ...
```

論文用のカテゴリは、既存6カテゴリに無理に当てはめず、論文の実態に合わせた新カテゴリをGeminiに判定させる(初期案: AI/機械学習、自然言語処理、コンピュータビジョン、その他)。

## 要約の観点を変える

論文はニュース記事と性質が異なるため、Geminiへのプロンプトはジャンルごとに指示を分ける:

- **テック(既存)**: 「何が起きたか」「なぜ重要か」を軸にした要約(現行のまま)
- **論文(新設)**: 「何を達成した研究か・手法・結果」を軸にした要約。ピックアップされた論文には、著者・投稿日等の論文特有のメタ情報も併記する

## 3段階モデルとの関係

`docs/roadmap/account-personalization.md`の3段階モデルに沿い、論文ジャンルも以下のように段階的に扱う:

- **未登録**: 論文ジャンルも含め全ジャンル・全カテゴリの一行あらすじ+ピックアップが見られる(現行のテックジャンルと同待遇)
- **無料登録**: 興味カテゴリ選択の対象にジャンル・カテゴリの両方を含める(「テックだけ」「論文だけ」「両方」等の組み合わせが選べる)
- **有料**: パーソナライズ型AI要約の対象にも論文ジャンルを含める(例:「特定の研究分野を優先して要約して」といった指示が論文にも適用される)

## 今後の情報源候補(未着手、書き留めのみ)

今回はArxiv論文のみを実装対象とする。以下は将来ジャンルを追加する際の候補として記録しておく(いずれも公開RSS/APIで認証不要、既存の調達方針に合致する):

- **テックジャンルの補強**: Hacker News(公式RSS/Algolia API)、Product Hunt(新製品ローンチRSS)、日経XTECH・CodeZine等の国内メディア
- **論文ジャンルの補強**: Hugging Face Daily Papers(コミュニティで厳選された注目論文。Arxivの全件配信を補完する「話題の論文」枠に向く)、Papers with Code
- **テック以外への本格拡張**: 科学ニュース全般(Nature News、ScienceDaily等のRSS)、ビジネス/スタートアップニュース
